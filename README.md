## 🔧 Development Setup

### Prerequisites
- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio or VS Code
- Git

### Getting Started
1. Clone this repository
```bash
git clone https://github.com/Shawon105176/Shawon105176.git
```

2. Navigate to project directory
```bash
cd Shawon105176
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```
